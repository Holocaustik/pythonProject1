# Руководство для контрибьюторов

Мы рады, что вы хотите внести свой вклад в проект! Пожалуйста, следуйте этим простым правилам:

1. **Создайте ветку**: Для каждой новой задачи или исправления создавайте отдельную ветку (feature/ или bugfix/).
2. **Соблюдайте стиль**: Старайтесь придерживаться существующего стиля кода в проекте.
3. **Тестируйте**: Перед отправкой Pull Request убедитесь, что ваш код не нарушает работу текущего функционала.
4. **Описывайте изменения**: В описании Pull Request четко укажите, какие проблемы решает ваш код или какие функции были добавлены.
